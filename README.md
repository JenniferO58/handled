# Handled: logistics concierge prototype

A clickable prototype for an event, celebration and travel logistics concierge in London.
**You make the plans. We handle the logistics.**

It's a single self-contained file (`index.html`). There's no build step, and no server or database is needed.

## What's inside

- **Website:** Home, Services, How it works, About, FAQs, Legal
- **Request forms:** Plan my journey (full or quick request) and Need help today
- **Customer dashboard:** booking status, journey timeline, WhatsApp-style chat
- **Operator dashboard:** bookings, 10-stage workflow, supplier database, fees and settings
- **Mobile screens:** a phone-sized preview of the key screens

Use the bar at the top to switch between views and try the five colour palettes.

## Notes

- Demo data is saved in your own browser only (localStorage). Use *Operator dashboard, Fees and settings, Reset all demo data* to start fresh.
- Transport services are fulfilled through appropriately licensed third-party providers. The final booking and payment structure is to be confirmed before launch.
